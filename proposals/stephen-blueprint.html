subsystem :: ai-pipeline (SkillSnap.me · prod)
ai-pipeline :: skillsnap.meSERVICE · serverless · solo build · concept→revenue <8wk▶

AI résumé & cover-letter SaaS. Built solo in early 2026 — empty repo to revenue-positive in under eight weeks — including the entire business: pricing, automated support, Stripe billing. Request flow:

user upload→ Cognito auth→ API / Lambda→ SQS queue→ RAG: embed + retrieve→ Bedrock — multi-model gen→ DynamoDB + S3→ CloudFront deliver→ Stripe billing
AWS Bedrock
Multi-model LLM generation — tailored documents, not generic templates.
RAG / embeddings
Embedding-based retrieval feeds the model the right context per job posting.
Lambda
All compute serverless — request handling, generation orchestration, webhooks.
SQS
Decouples generation jobs; back-pressure + retries.
DynamoDB
User state, document metadata, job status.
S3
Document storage — inputs, generated PDFs, assets.
CloudFront
CDN delivery for the app + hosted résumés (this résumé runs here).
Cognito
Auth / identity.
Stripe (ext)
Subscriptions, billing, the actual revenue.
Claude Skills / MCP
Tooling layer; orchestrating teams of Claude Code agents during the build.
Cursor
AI-assisted development environment, daily driver.
Python
Primary implementation language; Rust where it earns its keep.
